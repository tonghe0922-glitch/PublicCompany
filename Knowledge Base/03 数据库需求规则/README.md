# 上金谷运营管理平台数据库架构设计包 V1.0

本交付包依据“全部业务流程简表”及三端流程字段包生成，覆盖员工端、中心管理端、技术后台端共126个业务闭环。

## 核心规模

- 流程：126个；三端流程记录：378条
- 表单：2,164份
- 原始字段定义：90,124条；唯一数据库字段：445个
- 状态节点：3,138条；业务规则：4,836条；接口配置：2,697条
- 规划数据库：3个核心PostgreSQL库；物理Schema实例：46个；物理表：265张；字段字典：7,116行

## 目录

- `00_完整交付清单.md`：完整交付规模、目录、落库原则与最终校验结论。

- `01_架构设计`：总体架构、分库分域、建模规则、字段逻辑、安全审计、运维和实施方案。
- `02_数据字典`：数据源、Schema、全量表、字段、关系、索引、流程落表映射及机器可读JSON。
- `03_SQL_DDL`：三库可执行PostgreSQL 16 DDL、索引、外键、RLS、触发器、视图和初始化SQL。
- `04_初始化数据`：126流程目录、状态、业务规则、接口、三端联动CSV。
- `05_ER模型`：核心平台和各领域Mermaid ER模型。
- `06_规则与验收`：结构验收SQL、上线清单。
- `07_源材料映射`：90,124条原始字段到目标表/字段的逐条追溯映射。

## 重要实施原则

1. 三端共用同一业务事实，不按端口复制业务表。
2. 稳定字段落领域主表；明细、关系、附件、动态字段分别落专用子表。
3. 业务状态只能由服务端状态机迁移。
4. 同一事务写业务事实、流程轨迹和Outbox事件。
5. 审计库只增不改，分析库只由CDC/ETL写入。
6. DDL为目标架构基线；上线前必须结合实际数据库版本、容量、法规保留期和第三方接口完成评审。
