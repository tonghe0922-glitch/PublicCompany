- P011：`score_type` 独立记录；员工分、主管分、权威数据分、校准分不得覆盖成一个来源不明分数。

- P013/P014：来源事实键和影响项必须防重复；同一事实不得重复奖励或重复处分。
- P014：调查、决定、申诉复核必须执行回避；被调查人、原决定人不得担任对应独立复核人。
- P015：积分事实 append-only；更正只能新增 ADJUST/REVERSAL 流水。
- P016：资格、审批、执行、员工确认、对账、归档缺一不可；财务/服务能力不可用时 fail-closed。
