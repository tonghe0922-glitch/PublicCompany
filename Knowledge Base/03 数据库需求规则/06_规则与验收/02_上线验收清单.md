# 数据库上线验收清单

- [ ] 生产、测试、开发数据库和对象存储完全隔离。
- [ ] 应用账号非超级用户、无建库建Schema权限、无BYPASSRLS。
- [ ] 所有密钥和数据库密码进入密钥管理系统，不写配置文件和代码仓库。
- [ ] 126个流程落表映射由业务Owner、产品、研发、DBA共同签字确认。
- [ ] 所有P2/P3字段完成加密/脱敏/访问审计测试。
- [ ] 幂等、乐观锁、重复回调、消息重复消费测试通过。
- [ ] 状态机非法跳转、越权审批、本人审批本人、四眼复核测试通过。
- [ ] 金额、库存、积分、票务流水可从流水重新计算余额。
- [ ] 外部系统超时、断网、重复回调、死信和人工补偿测试通过。
- [ ] 全量备份、时间点恢复、对象存储恢复、审计链核对演练通过。
- [ ] 慢SQL、锁等待、连接池、复制延迟、磁盘、WAL、消息积压监控已告警。
