# 权限、敏感数据与审计规则

## 权限模型

采用 RBAC + ABAC + PostgreSQL RLS：

- RBAC：岗位/角色决定可执行动作。
- ABAC：组织路径、所属中心、责任人、业务状态、风险等级、时间窗口共同决定数据范围。
- RLS：所有带tenant_id的表强制租户隔离；应用连接不得BYPASSRLS。
- 字段级控制：P2/P3字段由服务层字段权限矩阵控制，不直接向通用查询接口暴露。
- 高风险动作：工资、证件、批量导出、权限授予、退款、发布、销毁、事故结案需要MFA及四眼复核。

## 敏感级别

- P1 内部：普通业务字段，按岗位和组织范围访问。
- P2 个人：姓名、联系方式、员工资料；传输加密、展示脱敏、导出审批。
- P3 高度敏感：证件、密码、健康、薪资、签署证据、密钥；字段级加密、密钥分离、访问逐次审计。

## 审计不可变性

审计日志至少记录：租户、操作者、当前身份、动作、对象、前后值摘要、规则/流程版本、原因、时间、请求ID、设备/IP、附件哈希。审计库只增不改，应用角色无UPDATE/DELETE/TRUNCATE权限。
